# Team 666 AI Text Evasion Submission

This package contains the Team 666 submission files, reproducibility scripts, and technical report for the AI_Text Evasion track.

## Files

- `results/666_test_1.csv`: final CSV submission file with columns `prompt,text`.
- `results/666_test_1.zip`: compressed version of the final CSV for email delivery.
- `results/humanize_plus_233_val.csv`: validation-set evasion output generated by the final pipeline.
- `results/evasion_233style_best_val.csv`: validation-set output generated by the character-level evasion pipeline.
- `scripts/humanize_rules_evasion.py`: rule-based humanization script.
- `scripts/evasion_233style.py`: character and formatting perturbation script.
- `scripts/char_nb_baseline.py`: lightweight local detector used for sanity-check evaluation.
- `scripts/llm_rewrite_evasion.py`: optional OpenAI-compatible rewrite pipeline template.
- `docs/technical_report.md`: technical report.

## Submission

Send `results/666_test_1.zip` by email. The archive contains `666_test_1.csv`.
